# 材质属性（Material Properties）



## ? TEXTURE TRANSFORM（纹理变换）

**作用**：控制贴图在模型表面的显示方式
常用于**缩放、平铺、旋转、偏移 UV**

* **Tiling (X / Y)**：平铺次数（重复纹理）
* **Offset (X / Y)**：UV 偏移
* **Rotation**：纹理旋转
* **UV Channel**：使用第几套 UV（UV0 / UV1）

? 用途：

> 地面重复贴图、流水偏移、动画 UV



## ?? AMBIENT（环境光）

**作用**：材质在**环境光**下的基础受光颜色

* 影响物体在无直射光时的亮度
* 常与 **Skybox / Ambient Light** 配合

? PBR 模式下通常影响较弱，更多依赖环境贴图



## ? DIFFUSE（漫反射 / 基础色）

**英文**：Diffuse / Albedo
**作用**：材质的**基础颜色或颜色贴图**

* 非金属材质的主要颜色来源
* 不包含高光、反射信息

? 示例：

> 木头颜色、塑料颜色、墙体底色



## ? SPECULAR（镜面反射）

**作用**：控制**高光颜色和强度**（非金属工作流）

* 决定“反光点”是什么颜色
* 在 **Metalness = 0** 时更明显

? 说明：

> PBR 推荐用 Metalness，但 Specular 仍用于特殊材质



## ? EMISSIVE（自发光）

**作用**：材质**自身发光，不受光照影响**

* 颜色 + 强度
* 可使用 Emissive 贴图

? 常见用途：

> 屏幕、灯牌、按钮高亮、科幻能量条



## ? OPACITY（透明度）

**作用**：控制材质透明程度

* 0 = 完全透明
* 1 = 不透明
* 通常需配合 **Blend Mode**

? 常见用途：

> 玻璃、水、UI 面片、半透明特效



## ? NORMALS（法线）

**英文**：Normal Map
**作用**：模拟表面凹凸细节（不增加面数）

* 影响光照和高光
* 不改变模型轮廓

? 极其重要

> 几乎所有写实材质都会用



## ? PARALLAX（视差 / 高度）

**作用**：利用高度贴图制造“深度错觉”

* 比 Normal 更有立体感
* 会增加一点性能消耗

? 常见用途：

> 砖墙、地面裂纹、浮雕效果



## ? CLEARCOAT（清漆层）

**作用**：在材质表面叠加一层“透明高光层”

* 独立高光
* 不影响底层材质

? 典型材质：

> 汽车漆、钢琴漆、上光塑料



## ? SHEEN（织物光泽）

**作用**：模拟**布料、纤维边缘光泽**

* 常见于衣服、布艺
* 高光偏柔、偏边缘

? 示例：

> 丝绸、天鹅绒、毛织物



## ? REFRACTION（折射）

**作用**：模拟光线穿过物体的**折射效果**

* 与透明度一起使用
* 会影响背景扭曲

? 典型材质：

> 玻璃、水晶、水体



## ? IRIDESCENCE（虹彩 / 干涉色）

**作用**：根据视角变化产生颜色变化

* 类似肥皂泡、油膜
* 高级 PBR 效果

? 示例：

> CD 表面、昆虫外壳、科幻材质



## ? ENVIRONMENT（环境反射）

**作用**：控制材质对**环境贴图（Skybox）**的反射

* 反射强度
* 反射模糊度（与 Roughness / Gloss 相关）

? 金属材质高度依赖此项



## ? LIGHTMAP（光照贴图）

**作用**：使用**烘焙光照结果**

* 不参与实时光照计算
* 性能极佳

? 常见于：

> 静态场景、建筑、室内



## ?? OTHER（其他）

常见包含：

* **Cull Mode**：剔除正面 / 背面
* **Depth Write / Test**：深度测试
* **Blend Mode**：混合方式
* **Alpha Test**：透明裁剪
* **Two Sided**：双面渲染

? 多用于特殊渲染或性能控制



## ? 一句话速记版

| 分类                   | 核心作用     |
| -------------------- | -------- |
| Diffuse              | 看起来是什么颜色 |
| Normal               | 看起来是否有细节 |
| Metal / Specular     | 是否像金属    |
| Gloss / Rough        | 反光清不清    |
| Emissive             | 自己会不会亮   |
| Opacity / Refraction | 透不透明     |
| ClearCoat / Sheen    | 高级材质增强   |
| Environment          | 反射环境     |
| Lightmap             | 烘焙光      |
