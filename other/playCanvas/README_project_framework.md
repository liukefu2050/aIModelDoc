## 一、3D 数字孪生核心（PlayCanvas 架构）

### 🎮 3D 引擎（核心中的核心）

* **PlayCanvas Engine**
**定位**

> 设备运动、状态可视化、报警高亮、场景管理
> 👉 **一切“真实世界的映射”都在这里**

---

### 📦 PlayCanvas 官方 / 半官方生态（强烈推荐）

| 库                 | 用途                  | 必要性   |
| ----------------- | ------------------- | ----- |
| playcanvas        | 引擎核心                | ⭐⭐⭐⭐⭐ |
| pcui              | PlayCanvas 官方 UI 组件 | ⭐⭐⭐   |
| glTF Loader（内置）   | CAD → glTF 模型加载     | ⭐⭐⭐⭐⭐ |
| Ammo.js / Oimo.js | 简单物理（限位/碰撞）         | ⭐⭐    |
| Basis / KTX2      | 纹理压缩                | ⭐⭐⭐⭐  |

⚠️ **注意**

* 不建议上复杂物理仿真
* 工业孪生 ≠ 游戏物理

---

## 二、Web 前端业务层（React 技术栈）

### ⚛️ 核心框架

* **React**

    * 用于**业务系统**
    * 不直接操作 3D（只发事件）

---

### 🧠 状态管理（推荐组合）

| 库         | 用途    | 说明          |
| --------- | ----- | ----------- |
| Zustand   | 全局状态  | 轻、简单、工业项目首选 |
| Jotai（可选） | 原子状态  | 参数配置场景好用    |
| immer     | 不可变数据 | 避免状态污染      |

🚫 不推荐：Redux（过重）

---

### 🔄 React ↔ PlayCanvas 通信

| 库 / 方案      | 用途         |
| ----------- | ---------- |
| mitt        | 事件总线（强烈推荐） |
| CustomEvent | 浏览器原生事件    |
| postMessage | iframe 场景  |

> **原则**：
> React 管业务 → 发事件
> PlayCanvas 听事件 → 改 3D
