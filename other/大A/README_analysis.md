常用技术分析

## 一、进入股票详情页


## 二、行情区

### 涨跌额 / 涨跌幅（%）

+5% 以上：明显强势
-5% 以下：明显走弱

### 今开 / 昨收 / 最高 / 最低

高开低走：当天可能弱
低开高走：可能有资金承接

---

## 三、成交数据（判断资金活跃度）

### 成交量、成交额

放量上涨：健康
缩量上涨：可能是假涨
放量下跌：危险

---

## 四、五档盘口（短线必看）

### 买一 / 卖一

买一：当前最高愿意买的价格
卖一：当前最低愿意卖的价格

### 买卖盘数量

买盘大：有人想接
卖盘大：抛压重

快速判断

买一到买五明显大于卖盘 → 短线偏强
卖盘压着价格 → 容易下跌

---

## 五、估值数据（中长期一定要看）


### 市盈率（PE）

股价 ÷ 每股盈利
衡量贵不贵

| PE情况  | 含义    |
| ----- | ----- |
| < 15  | 偏低估   |
| 15–30 | 正常    |
| > 50  | 高估或炒作 |

亏损公司 PE 可能为负，不具参考意义

---

### 市净率（PB）

股价 ÷ 每股净资产
看资产值不值

常见判断：

PB < 1：可能被低估（也可能公司差）
PB > 3：偏贵

---

## 六、公司基本面（避坑必看）

在「资料 / 财务 / F10」里

### 总市值 / 流通市值

总市值：公司整体大小
流通市值：市场真正能炒的部分

小市值：波动大，容易暴涨暴跌
大市值：稳，但涨慢

---

### 净利润 / 营收（同比）

看有没有增长
连续下滑 = 风险

---

## 七、最稳的“5秒检查法”


1. 今天涨跌幅
2. 成交额是否明显
3. 是否放量
4. 市盈率是否离谱
5. 最近是不是连续下跌

5 个里 3 个不对，直接跳过

---

## 八、技术指标分析

1. 技术分析中，查看套牢盘占比情况
2. 量价分布中，查看 成交密集区（在某个价格，绿条比红条长 → 买盘更强
   红条比绿条长 → 卖压更重）  
   每笔均量（大单还是小单：单位100股）
3. 套牢盘看主要筹码集中区，价格在附近就要抛（大量套牢盘只适合做短信，压力大）
