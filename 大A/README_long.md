# 大A长期持股策略


### 规避的规则

- 规避：强周期（煤炭、钢铁短炒）、纯概念炒作
- 规避：任何时候满仓操作
- 规避：估值明显泡沫（全市场疯狂）
- 规避：连续加息、政策强压期重仓
- 规避：下调15%以内就急于建仓
- 规避：大盘快速下跌、几乎所有板块一起跌、宏观流动性问题

### 持有条件

公司基本面(业绩、前景)没变坏
行业逻辑还在
不是靠“概念”上涨

### 卖出条件（满足一条即可）

基本面恶化（连续 2–3 个季度业绩下滑）
行业趋势反转（政策/技术替代）
严重高估（明显泡沫）
你当初买入的逻辑不存在了

不是因为回调卖出，而是因为逻辑没了

### 仓位管理（非常重要）

单只股票 ≤ 30%
采用分批建仓（3 次为宜）

大涨后的仓位管理规则：
- 股票大涨后，优先判断上涨性质（估值修复 / 基本面 / 情绪）
- 不因价格上涨而卖出，只因估值和逻辑变化而调整仓位
- 单股仓位超过 40% 时，原则性减仓
- 减仓仅针对超额部分，保留核心长期仓位
- 情绪性暴涨必须降低风险敞口


### 行业选择（只选确定性高的）

优先级排序：

消费龙头（白酒、食品、调味品）
医药（创新药、医疗服务）
高端制造 / 新能源（龙头）
科技核心（半导体、AI 应用）

- 行业确定性
- 商业化路径
- 财务验证
- ROE 支撑


### 个股筛选标准（照着选）

满足 5 条以上 才考虑：

行业前三
连续 3 年盈利
ROE净资产收益率 ≥ 15%  （公司一年赚15元 / 股东投入100元）
净利润长期增长
负债率合理
现金流为正
实控人/管理层稳定

优先在：
    - 行业/市场恐慌期
    - 个股回调 15%–30%
    - 估值回到历史中低位

### 复盘规则
每半年复盘一次
只做三件事：
    1. 基本面是否变化
    2. 行业趋势是否还在
    3. 估值是否偏离合理区间

问自己 3 个问题：
行业 3–5 年后是否还存在？
是否被政策或技术彻底否定？
龙头公司是否还能赚钱？

当前估值 vs 历史估值
是否回到中位数以下
行业是否过度集中
